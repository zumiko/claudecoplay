coplay

    MIT · github
  


  
Play while Claude works. The game freezes the instant Claude needs you, and resumes when it gets back to work.


  

  


  
install

  
Three steps. The first is a one-off, and you may have it already.


  
1. Install tmux. The games run in a tmux pane, so this is a hard requirement rather than a nicety.

  

    
    
brew install tmux          # macOS
sudo apt install tmux      # Debian / Ubuntu

  


  
2. Install the plugin, from inside Claude Code:

  

    
    
/plugin marketplace add USER/REPO
/plugin install coplay@coplay

  

  
Restart Claude Code so the hooks load.


  
3. Get Claude running inside tmux. A session already running outside tmux can't be moved into one — but this reopens your current conversation in tmux, so you lose nothing:

  

    
    
tmux new -s coplay 'claude --continue'

  


  
Then type /snake, /tetris or /asteroids.

  
Steps 1 and 3 are also bundled: the repo's bin/coplay offers to install tmux for you, then starts Claude inside it. And /coplay reports exactly what is and isn't wired up, including the command above if you need it. Needs Node 16+ as well; no npm dependencies — the games use only fs, os and path. Nothing is ever written to your settings.json: the hooks ship inside the plugin, so uninstalling removes them completely.


  
the games

  

    
/snake — arrows to steer

    
/tetris — arrows, space drops

    
/asteroids — turn, thrust, fire

  

  
/coplay shows status, which game is running, and your local high scores.


  
how it works

  
The whole thing is one word in a file. Claude Code hooks write it; the game polls it every tick.

  

    
hook eventwrites

    
SessionStartWORKING

    
UserPromptSubmitWORKING

    
PreToolUseWORKING

    
PostToolUseWORKING

    
NotificationPAUSED

    
StopPAUSED

    
SessionEnddeletes the file

  

  
Each hook is a plain echo, so nothing starts an interpreter and the cost is a couple of bytes per event.

  
    
    
  • Focus follows the work. Submit a prompt and the keyboard moves to the game; the moment Claude needs you it moves back. Press f to turn that off.
    • 
    
  • Death is free. Press r, or just send Claude a new prompt — the game restarts on the same edge that resumes it.
    • 
    
  • The pane cleans itself up. SessionEnd deletes the state file, the game notices and closes, so panes never linger.
    • 
    
  • Concurrent sessions don't collide. The state file is keyed by $CLAUDE_CODE_SESSION_ID, so two Claudes never stomp on each other.
    • 
  


  
notes

  
    
    
  • Claude has to already be running inside tmux — the game needs a pane to split into.
    • 
    
  • One game at a time. Starting a different one closes the old pane, so there's never a question about which game has the keyboard.
    • 
    
  • Resizing never disturbs a run. If the pane gets too small the game waits behind a notice instead of drawing a broken frame.
    • 
    
  • High scores live in ~/.claude-coplay/scores.json.
    • 
    
  • Uninstall: /plugin uninstall coplay. It leaves nothing behind but that scores file.
    • 
  


  
add your own game

  
The engine owns the terminal, the pane sizing, the pause/resume and the chrome. A game is one file:

  
engine.run({
  id: 'pong', title: 'PONG', tickMs: 60,
  controls: 'arrows to move',
  minCols: 20, minRows: 10,
  dims: (w, h) => ({ w, h }),
  create: (w, h) => ({ score, dead, step(), key(k), rows() }),
});

  
Drop it in games/, add a matching command file, and /coplay picks it up automatically.
